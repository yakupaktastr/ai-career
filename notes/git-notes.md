# GIT NOTLARI
Bu not defteri, git çalışırken öğrendiğim bilgileri yazılı hale getirmek için ve bilgilerimi pekiştirmek için yapay zeka yardımı ile soru cevap yapmak için oluşturuldu.

## GIT NEDIR
Git, bir versiyon kontrol sistemidir(vcs). Bir proje geliştirilirken projenin üzerinde birden fazla çalışanın aynı anda çalışabilmesini, projenin birden fazla sürümünün kayıt altında tutulabilmesini ve gerektiği zaman eski sürümlere geçilebilmesini ve lokalde çalışılan projenin sunucu tarafına güvenli bir şekilde iletilebilmesini sağlar.

## GITHUB NEDIR
Github, git kullanılarak geliştirilen bir projenin bulut üzerinde depolanmasını veya yayına alınmasını sağlayan platformdur.

## GIT MIMARISI
Bir projemizde git kullanıyorsak, burada git mimarimizi üç ana alandan oluşur. Bunlar **Working Directory**, **Staging Area** ve **Repository**'dir.
